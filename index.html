Como usar

Esta página é o design system inteiro: o CSS está embutido nela, no bloco <style id="atlas-css">. Baixe ou copie o CSS abaixo, inclua na sua tela e marque a raiz da página com atlas-root. O tema vem de data-theme (dark ou light). As cores vivem em .atlas-root, então os componentes precisam estar dentro dele. Todas as classes começam com atlas- e não colidem com o CSS de uma página existente.

<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800&display=swap">
<link rel="stylesheet" href="atlas.css">

<body class="atlas-root" data-theme="dark">
  <main class="atlas-appContainer">
    <section class="atlas-sectionCard">…</section>
  </main>
</body>

Marca

Três versões do logo. Na tela, use o componente com fill="currentColor": ele fica branco no tema escuro e quase preto no claro, sem trocar de arquivo. Os arquivos oficiais, nas duas cores, ficam em public/brand/ do portal.

Horizontal
Barra de navegação. Altura de 24 a 28 px.
Vertical
Login e telas de abertura, centralizado. A partir de 80 px de altura.
Símbolo
Ícone da aba, avatar do agente, barra em tela estreita. A partir de 16 px.

Raio e profundidade

Quatro raios: pequeno para campos, médio para itens dentro de cartões, grande para cartões e pílula para botões e filtros. A profundidade é sutil — sombras escuras e um topo levemente iluminado no tema escuro.

Botões

Um botão lime por área — é a ação principal. Os demais são neutros. Link de ação serve para ações dentro de linhas de tabela.

Abas trocam de visão dentro de um cartão. Pílulas de filtro restringem uma lista. Os dois marcam o ativo em lime.
